Icon Werkbank

Lade ein Icon und prüfe, wie es sich gegen ein Interface verhält. Die Regler entstehen aus den Typen des Interfaces. Du brauchst dafür weder das Plugin noch ein Gerät.

2. Interfaces

Die Primitive des Kerns sind eingebaut. Ein eigenes Interface eines Plugins muss geladen werden, sonst weiß die Werkbank nicht, welche Eigenschaften es hat und welchen Typ sie tragen.

Geladene Interfaces von Plugins bearbeiten

3. Werte der App

Ein Regler je Eigenschaft des gewählten Interfaces. Nimm den Haken weg, um zu sehen, was passiert, wenn die App den Wert nicht liefert. Dann greift der fallback.

4. Signale und Theme

Signale, die das Icon direkt bindet, und die Theme Variablen, die es liest. Variablen außerhalb der Kernvariablen sind anfangs nicht gesetzt.

5. Je Rolle

Das Icon einmal je genannter Rolle, jeweils nur mit den Eigenschaften dieser Rolle. So sieht es auf Apps aus, die nur dieses eine Interface erfüllen.
